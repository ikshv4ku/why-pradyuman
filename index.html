Why harness engineering matters

Same model, different harness, very different results.

That gap is the job. On Terminal-Bench 2.0, swapping only the harness moved one model by almost 16 points.

Why a chariot

“Harness” is horse tack.

It is the gear that turns a powerful horse into a chariot that goes where you point it. The Kaṭha Upaniṣad drew the same diagram for the mind, and it reads like an agent architecture.

And this metaphor isn’t borrowed: I played the lead in a classical Sanskrit play, and I volunteer with the Sanskrit Club.

आत्मानं रथिनं विद्धि शरीरं रथमेव तु ।बुद्धिं तु सारथिं विद्धि मनः प्रग्रहमेव च ॥

Station 5 of 5

Mārga मार्ग

The road is the Meet, 11–14 Dec, IIT Guwahati

Measure a bare baseline early, then win on the delta.

The sentence to earn: “Same model, our harness: X% to Y% at Z% of the cost per solved task.” LangChain moved one model from 52.8% to 66.5% on Terminal-Bench 2.0 this way.

0:00a 12-hour build, scaled to the real clock12:00
  1. 0:00Read and define. One-line metric; 10–20 auto-graded evals
  2. 0:45Baseline. Bare loop, JSONL traces, three runs
  3. 1:45Tools. Absolute paths, terse errors, spill to files
  4. 3:30Verification. Checks tool, completion gate, loop detector
  5. 5:00Context. Short AGENTS.md, compaction at ~60%
  6. 6:30Safety. Workspace-only writes, step and dollar budgets
  7. 7:15Trace-driven fixes. One fix per failure mode
  8. 9:30Ablations. Remove one part at a time
  9. 10:30Demo. Results table, live trace, recorded fallback

What I’d build next

Six ideas I’d bring, each grown from work I’ve done.

These are proposals, not shipped products. Each one extends something on this page.

Idea, not shipped

Black Box: a flight recorder for agents

I’d give every agent run, subagent and MCP call one correlation ID in standard OTel GenAI spans, with sampling that never drops a failed trajectory. A triage agent then pins each failure to a phase and files one root-cause fix.

Grows fromMy request-path observability at Databricks: correlation IDs, failure-phase attribution, sampling that never drops a failure.

Idea, not shipped

Value Router

At session start, I’d pick the cheapest model-and-effort setup likely to solve the task and lock it, so prompt-cache hits survive. The executor calls a frontier advisor only on hard turns, and the router is scored on cost per solved task, not tokens spent.

Grows fromMy value-maxxing tiers and my efficiency-vs-cost model report.

Idea, not shipped

Skillsmith: a critic that writes skills

When my self-critique skill flags the same mistake across sessions, Skillsmith drafts a SKILL.md patch from the trajectories that avoided it. The patch merges only if it beats the no-skill baseline on held-out tasks, with its context cost measured first.

Grows fromMy self-critique skill and my work on Isaac’s skills.

Idea, not shipped

Dream Journal

Each night, a pass re-reads the day’s raw transcripts and checks my daily, weekly and monthly journal pages against them, fixing any drift. Changed facts are superseded with valid-time stamps, never overwritten, so “what did we believe on 12 July?” stays answerable.

Grows fromMy work-journal agent and SMRITI’s bi-temporal ledger (a design).

Idea, not shipped

Context Flame Graph

I’d attribute every context token on every turn to its source (system prompt, skill, MCP schema, memory file, tool result) and draw it as a flame graph, with the cache-hit share alongside. That turns my “2–3× below the intern cohort” from a dashboard number into an explanation any team can reproduce.

Grows fromMy filesystem memory and my work on Isaac’s skills and context.

Idea, not shipped

Quarantine Scribe

Untrusted text from Slack or the web is read only by a quarantined extractor, which may emit typed SMRITI cards but never instructions or tool calls. A separate clean-context reviewer approves each write-back before it reaches the memory every agent reads.

Grows fromSMRITI and my shared markdown memory.
